# Ngaa-Tai-E-Rua-Paa

## Setup

### Requirements

* Docker Desktop installed

### Start project

Clone repo:

```bash
git clone https://github.com/jeniT-T/Ngaa-Tai-E-Rua-Paa
cd marae-app
docker compose up --build
```

Create env file:

```bash
cp .env.example .env.local
```

Run project:

```bash
docker compose up --build
```

Open:

http://localhost:3000

### Stop containers

Press:

CTRL + C
